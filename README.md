# Tестовое задание

Top-down shooter на Unity. Весь код проекта — в `_Project/Code`.
Основной упор сделан на damage pipeline с модификаторами атаки/защиты и визуальными модификаторами + небольшая система способностей
Может иметь нюансы из за определенного ТЗ.

## Стек
- **VContainer** — DI
- **UniTask** — асинхронность
- **R3** — реактивность
- **uPools** — пулинг
